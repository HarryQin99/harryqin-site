# Harry Qin

Source for my personal site: a short intro and longer write-ups of projects I've built.

Built with [Astro](https://astro.build) and deployed on Vercel.

```sh
pnpm install
pnpm dev        # local dev server
pnpm test:e2e   # Playwright tests against a production build
```

Projects live in `src/content/projects/` as Markdown, one file each.
